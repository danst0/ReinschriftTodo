# Code of Conduct

This project follows the [GNOME Code of Conduct](https://conduct.gnome.org/).

In short: be friendly, be empathetic, be respectful, be considerate, be
patient, be generous in interpreting the actions of others — and choose
kindness over conflict. This applies to issues, pull requests, and all other
project spaces.

Concerns about behavior in this project's spaces can be reported to the
maintainer at <reinschrift@dumke.me>.
